## Notes and discrepancies

- **08-capacity-cards.png**: The breakdown lines are always visible on these cards; nothing needed expanding.
- **12-kanban.png**: Captured at a temporarily widened viewport (2600px) so all eight columns are visible; the board scrolls horizontally at the standard 1440px.
- **13-actual-hours-prompt.png**: Dismissed with Escape (the dialog's cancel path) after capture, so the task's status was not changed.
- **14-retro-notes.png**: Discrepancy vs. brief: seeded retrospective text exists only on completed sprints, so this shows Sprint 0 · Performance hardening (an Aurora Living E-Commerce sprint), not Sprint 1.
- **27-client-forbidden.png**: Observed behaviour: redirect to /portfolio rather than a rendered 403 page; the UI guard is cosmetic, the API is the security boundary.
